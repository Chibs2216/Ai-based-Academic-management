# Styles

Files load in this order (later files can override earlier ones):

| File | What it styles |
|---|---|
| `tokens.css` | Colors, spacing, font sizes (CSS variables). Change the theme here. |
| `base.css` | Page reset and default text styles |
| `layout.css` | Sidebar + content layout of the portals |
| `components.css` | Buttons, inputs, cards, badges, tables |
| `pages.css` | Sign-in page and shared page sections |
| `dashboard.css` | Dashboard widgets |
| `portal.css` | Shared portal pieces (headers, lists) |
| `admin.css` | Admin-only screens (also used by teacher/student pages) |
| `app/header-actions.css` | Header buttons and the notification bell |
| `app/banners-states.css` | Banners, loading / empty / error states |
| `app/stat-tiles.css` | The small line under a stat number |
| `app/tables-mobile.css` | Tables on phone screens |
| `app/forms.css` | Form layout (rows, columns) |
| `app/modal.css` | Pop-up dialogs |
| `app/auth.css` | Sign-in steps (MFA, reset, sign-up) |
| `app/charts.css` | Charts |
| `app/progress.css` | Upload progress bar |
| `app/chat.css` | Chat / messages |
| `app/misc.css` | Pills, key-value lists, material viewer, extra badges |
